# Mini AI Research Agent

## Overview

Mini AI Research Agent is a beginner-friendly, educational prototype built with
Python and Streamlit. It demonstrates how an AI-powered research agent could
work by simulating a full research workflow — from planning to a final
report — using **local demo data only**.

This project is designed to be easy to read and understand for anyone
learning Python, while still following a clean, modular structure that can
later be upgraded to use real AI and web-search APIs.

## Features

- Simple, clean Streamlit web interface
- Enter any research topic and choose a research depth (Quick / Standard / Detailed)
- Step-by-step simulated agent workflow with live progress feedback
- Demo sources, analysis, and synthesis for several built-in topics
- Generic fallback response for any topic not in the demo dataset
- Auto-generated Markdown research report
- Download report as Markdown (`.md`) or plain text (`.txt`)
- Option to save reports into the local `reports/` folder
- Friendly error handling — the app will not crash on unusual input

## Demo Mode

**This version does NOT use any real AI APIs or live web search.**

There is no Claude API, OpenAI API, or any other paid/external API involved.
All "research" shown in the app comes from structured demo data stored in
`mock_data.py`. Every report generated by the app clearly displays a
**DEMO MODE** notice explaining this.

This approach lets us build and demonstrate the full agent *workflow* first,
before wiring up real, costly, or rate-limited external services.

## How the Agent Works

The agent simulates the following pipeline:

```
User Input
   -> Research Planning        (create_research_plan)
   -> Source Discovery         (discover_sources)
   -> Information Collection   (collect_information)
   -> Analysis                 (analyze_information)
   -> Synthesis                (synthesize_findings)
   -> Final Report             (generate_report)
```

Each stage is a separate function in `research_agent.py`. `app.py` calls
these functions in order and displays the result of each stage in the
Streamlit UI, so the user can see the research process happening step by
step, rather than getting one big report all at once.

## Tech Stack

- Python 3
- Streamlit (web UI)
- Standard Python libraries only (`os`, `datetime`, `time`)

No external AI or search libraries are used in this demo version.

## Installation

These steps assume you are on Windows using PowerShell or Command Prompt.

1. **Create a virtual environment:**

   ```
   python -m venv venv
   ```

2. **Activate the virtual environment (Windows):**

   ```
   venv\Scripts\activate
   ```

3. **Install dependencies:**

   ```
   pip install -r requirements.txt
   ```

4. **Run the application:**

   ```
   streamlit run app.py
   ```

   Streamlit will open the app automatically in your browser (usually at
   `http://localhost:8501`).

## Future Development

This project is intentionally limited to demo/local data for now. Planned
future upgrades include:

- **Claude API integration** for real AI-generated analysis and synthesis
- **Real web search** (e.g. a search API) to replace the mock sources
- **Source extraction** — actually fetching and reading page content
- **Source credibility checking** to flag unreliable sources
- **AI-powered analysis** instead of pre-written demo templates
- **Automatic citations** formatted in standard citation styles
- **PDF report generation**
- **Research history** so past reports can be revisited
- **n8n automation** to trigger research runs from external workflows

## Disclaimer

All research content, sources, and findings in this application are
simulated for educational and demonstration purposes only. Nothing in this
app should be treated as real, verified research.
